# Nihad Şəfiyev

Statik portfolio və dizayn xidmətləri kataloqu. Ana səhifə `index.html`, ayrıca səhifələr `portfolio.html` və `about.html` fayllarındadır.

## Əlaqə və qiymətlər

- `catalog.js` faylındakı `studioContact.whatsapp` sahəsinə WhatsApp nömrəni ölkə kodu ilə, yalnız rəqəmlərlə yaz. E-poçt və Instagram sahələri istəyə görə doldurulur.
- Nömrə daxil ediləndə brief göndərmə düyməsi hazır mətni WhatsApp-da açır. Müştəri mesajı orada özü göndərir. Boş konfiqurasiyada forma mətni göstərir və kopyalamağa imkan verir.
- Eyni fayldakı `catalog` siyahısında xidmətlər, qiymətlər, düzəlişlər və təhvil faylları var. Qiymətlər sınaq üçün seçilib.

## İş nümunələri

- `projects.js` faylındakı `studioProjects` siyahısı ana səhifəni və portfolionu doldurur. Şəkilləri `assets/` qovluğuna qoy və faylın nisbi yolunu `img` sahəsinə yaz.
- Loqo kartının növbələşən şəkilləri həmin fayldakı `logoSamples` siyahısından gəlir. Mövcud beş şəkli öz işlərinlə əvəz edə bilərsən.
- Hazır materiallar konsept layihələrdir. Portfolio məlumatlarını və etiketlərini yayımladığın işə uyğun dəqiqləşdir.

## Yayımlama

ZIP-i aç və içindəki faylları repozitoriyanın kökünə yerləşdir. `index.html` birbaşa kökdə olmalıdır. Statik önizləmə üçün GitHub Pages-də `Settings → Pages → Deploy from a branch → main → / (root)` seç. Satış üçün yayımlayanda hostinq xidmətinin kommersiya şərtlərini nəzərə al. Saytın işləməsi üçün build əmri, Node.js prosesi və verilənlər bazası lazım deyil.
